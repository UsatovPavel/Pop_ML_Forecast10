# Прогнозирование численности населения с использованием машинного обучения

Проект по прогнозированию численности населения на 10 лет вперёд с использованием различных методов машинного обучения и временных рядов.

## Описание проекта

Проект основан на статье "Application of machine learning algorithms for population forecasting, 2021". Цель — предсказать численность населения на 10 лет вперёд (2013-2022) для различных стран. Валидация проводится на России без учёта Крыма.

## Структура проекта

### 1. Сбор данных (`2.*.ipynb`)

#### 2.1. Сбор когортных данных (`2.1.collect_cohort_data.ipynb`)
- Сбор данных по возрастным когортам (5-летние группы) из источников:
  - UN Population Division (World Population Prospects 2024)
  - US Census Bureau IDB API
- Сбор данных по смертности (mortality) и фертильности (ASFR - Age-Specific Fertility Rate)
- Объединение данных из разных источников с приоритетом Census данных
- Формирование финального датасета с когортами, смертностью и фертильностью

#### 2.2. Сбор данных World Bank (`2.2.collect_more_wb_data.ipynb`)
- Загрузка демографических и социальных показателей через World Bank API:
  - Плотность населения
  - Урбанизация
  - Рождаемость и смертность
  - Ожидаемая продолжительность жизни
  - Миграция
  - И другие социально-экономические индикаторы
- Преобразование из широкого формата (страна × год) в длинный формат (страна, год, признак)
- Объединение с когортными данными

#### 2.3. Преобразование в матричный формат (`2.3.convert_matrix.ipynb`)
- Генерация признаков с временными сдвигами:
  - **DATA_RANGE = 25** — количество лет исторических данных
  - **PREDICT_RANGE = 10** — горизонт прогнозирования
  - Для каждого года `t` создаются признаки за годы `t, t+1, ..., t+25`
  - Целевая переменная `pop_plus_35` — население через 35 лет
- Фильтрация данных: `year <= 2022 - 25 - 10 = 1987`
- Создание трёх версий датасетов:
  - `filtered_25_predict10_pop.csv` — только население
  - `filtered_25_predict10_noncohort.csv` — без когортных признаков
  - `filtered_25_predict10_all.csv` — все признаки включая когорты

### 2. Прогнозирование (`3.prediction.ipynb`)
#### 2.1 Дополнительный grid ARIMA(`4.More_grid.ipynb`)

#### Структура данных для прогнозирования
- **Окно валидации для моделей с признаками:**
  - Train: 1960–1977 (18 лет)
  - Test: 1978–1987 (10 лет)
  - Целевая переменная: население в 2012 году (1977 + 35)
  
- **Окно валидации для моделей временных рядов:**
  - Train: до 2012 года
  - Test: 2013–2022 (10 лет)

#### Метрики оценки
1. **MAPE** (Mean Absolute Percentage Error) — средняя абсолютная процентная ошибка
2. **RMSE** (Root Mean Squared Error) — корень из средней квадратичной ошибки (нормализованный)
3. **SDEV** — стандартное отклонение абсолютных ошибок (показывает стабильность модели)

#### Baseline модели
1. **Naïve Forecast** — прогноз равен последнему известному значению
2. **Linear Trend** — линейная экстраполяция тренда

#### Используемые модели

| Модель | Тип данных | MAPE | RMSE относ | SDEV относ |
|--------|------------|------|------------|------------|
| ARIMA_grid | population | 0.020 | 0.024 | 0.013 |
| linear_regression | filtered_with_cohort | 0.027 | 0.034 | 0.020 |
| prophet | population | 0.030 | 0.034 | 0.014 |
| linear_regression | filtered | 0.040 | 0.051 | 0.029 |
| cohort_component | population_cohort | 0.056 | 0.059 | 0.015 |
| ARIMA | population | 0.070 | 0.082 | 0.039 |
| xgboost | all | 0.079 | 0.091 | 0.041 |
| linear_regression | population | 0.095 | 0.099 | 0.022 |
| RandomForest | all | 0.111 | 0.123 | 0.046 |
| naive | population | 0.196 | 0.202 | 0.041 |


| Тип данных             | Описание                                                                                       |
|------------------------|------------------------------------------------------------------------------------------------|
| population             | Численность страны по годам(страна, год, население)                                         |
| population_cohort      | Численность населения, фертильность, смертность по 5-летним когортам|
| filtered               | Демографические и социальные показатели|
| filtered_with_cohort/all   | filtered + когортные признаки       |

**Описание моделей:**

1. **ARIMA_grid** — ARIMA с подбором параметров через grid search (лучший результат)
2. **Linear Regression** — линейная регрессия с различными наборами признаков
3. **Prophet** — модель временных рядов от Facebook с подбором гиперпараметров
4. **Cohort Component Model** — демографическая когортная модель с учётом смертности, рождаемости и миграции
5. **XGBoost** — градиентный бустинг
6. **Random Forest** — случайный лес
7. **ARIMA** — базовая ARIMA модель

#### Прогноз для России

В проекте построены прогнозы численности населения России (без Крыма) на 2023-2032 годы с использованием лучших моделей. Результаты сравниваются с официальным прогнозом Росстата.

## Технические детали

### Обработка данных
- Фильтрация стран с населением < 1 млн человек
- Линейная интерполяция пропущенных значений (для признаков с < 33% пропусков)
- Удаление признаков с > 33% пропусков
- Обработка России без учёта Крыма (для корректной работы с данными после 2014 года)

### Особенности когортной модели
- Используются 5-летние возрастные группы
- Учитываются:
  - Смертность по возрастным группам
  - Возрастные коэффициенты рождаемости (ASFR)
  - Миграция (пропорционально существующим когортам)
- Сдвиг когорт на 1 год с учётом равномерного распределения внутри 5-летних групп

## Результаты

Лучшая модель — **ARIMA_grid** с MAPE = 0.020, что показывает высокую точность прогнозирования. Модели с когортными признаками (linear_regression с filtered_with_cohort) также показывают хорошие результаты (MAPE = 0.027).
